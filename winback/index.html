01 / THE BRIEF

Design a win-back experience for returning users.

Subscriptions lapse, but detection keeps running in the background, and the user never sees what was found. When they log back in: show what was found, and give a clear path to reactivate.

STEP 1 Subscribed Scanning · on Removing · on
STEP 2 Plan lapses Cancelled, or payment fails.
? STEP 3 · THE GAP Still scanning, not removing Scanning · on Removing · off Links pile up. The user never sees them.
STEP 4 · THIS PROJECT The win-back screen Reveal what happened in the gap, then one path back.
STEP 5 Reactivated Removals resume on the backlog.
THE TASK How might we get users who cancelled to subscribe again?

02 / HOW I READ IT

Show the track record, not a warning.

I read this screen as two things at once: a landing page that has to win users back, and a dashboard they still rely on. That raised my question: how do we bring people in the gap back without scaring them? My answer: design for a moment of loss without exploiting the fear. Build trust by showing the work already done.

06 / REFLECTION

Why this is in my portfolio.

I've always loved designing charts and data. This project is less about the result and more about an experiment: how far can I get on my own, in a short time, with AI?

BeforeChart work used to be slow. I set the display rules and values, then reviewed and fixed them with developers over many rounds.
NowWith AI, I can test edge cases and catch rule errors on my own, much faster.
The experimentThe challenge only asked for Figma screens. I built the prototype to prove I can use that speed well.

Faster checks lead to better decisions.
